​

素材管理-查询
请求方式及url
​
请求方式：
POST
请求头：
Content-Type:application/json
接口地址：
https://api.xiaoe-tech.com/xe.material.list/1.0.0
频率限制:
10秒3000次
接口调试
GET
POST
PUT
DELETE
https://api-doc.xiaoe-tech.com/_agent/forward?url=https://api.xiaoe-tech.com/

重置
请求参数
显示请求头

请求参数
​
参数名
必选
类型
说明
access_token
是
string
专属token
type
是
int
素材类型 1-图片 2-音频 3-视频 4-电子书 5-文档
sort_keyword
否
int
排序字段，默认为0； 0-主键id，1-material_size-文件大小，3-refer_count-被引用数，4-view_count-访问数，5-title-标题
sort_order
否
int
排序顺序，默认为1； 1-ASC顺序 2-DESC倒序
title
否
string
查询素材名称
cur_page
否
int
当前页码 默认为1
page_size
否
int
分页大小 默认10 最大不能超过100
upload_start_at
否
string
上传日期起始点
upload_end_at
否
string
上传日期截止点
请求示例
​
{
"access_token":"xe_xxxxx",
"type":1,
"cur_page":1,
"page_size":10
}
